## Screenshots upload order

Both stores need 6.7" / 6.9" iPhone screenshots. Order optimized to
convert shop owners (the audience that pays). The first 3 carry the
strongest message — App Store visitors usually decide from those.

1. `01-money-direct.png` — **เงินถึงคุณ 100% · 0% ค่าธรรมเนียม** (lead hook: PromptPay direct to seller's bank, no middleman)
2. `02-open-shop-free.png` — **เปิดร้านฟรี · ขายได้ทันที** (seller dashboard + KYC verified)
3. `03-ai-migrate.png` — **AI ย้ายของจากร้านเดิม** (1-click product import — the migration pitch)
4. `04-customers-find-you.png` — Home feed (where buyers discover your shop)
5. `05-orders-one-place.png` — Order management
6. `06-trust-verified.png` — Verified badge + trust score

App Store accepts the same set under "iPhone 6.9 inch Display" and copies
down to smaller sizes automatically. Play Console: upload as Phone screenshots,
2-8 images.
